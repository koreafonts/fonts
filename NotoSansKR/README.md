## 웹폰트 적용

KoreaFonts 소유 jsDelivr 배포 버전을 사용합니다.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/koreafonts/fonts@cdn-017-v3/NotoSansKR/koreafonts.css">
```

```css
@import url('https://cdn.jsdelivr.net/gh/koreafonts/fonts@cdn-017-v3/NotoSansKR/koreafonts.css');
```

직접 선언하는 경우:

```css

  font-weight: 100;
  font-style: normal;
  font-display: swap;
```
