# 모이라이 — KoreaFonts

KoreaFonts에서 제공하는 설치용 원본 폰트와 웹폰트입니다. 폰트의 저작권은 원 제작자에게 있습니다.

- 제작자: 박지연, 자모
- 원본 배포처: https://fonts.google.com/specimen/Moirai+One
- 라이선스: [LICENSE.txt](LICENSE.txt)

## 설치용 원본 다운로드

TTF·OTF 파일은 내려받은 뒤 운영체제에 설치해 사용할 수 있습니다. 가변 폰트는 파일명에 표시합니다.

| 파일 | 형식 | 크기 |
|---|---|---|
| [MoiraiOne-Regular.otf](https://github.com/koreafonts/fonts/raw/refs/heads/main/MoiraiOne/MoiraiOne-Regular.otf) | OTF | 5.15 MB |
| [MoiraiOne-Regular.ttf](https://github.com/koreafonts/fonts/raw/refs/heads/main/MoiraiOne/MoiraiOne-Regular.ttf) | TTF | 2.00 MB |

## 웹폰트 적용

KoreaFonts 소유 jsDelivr 배포 버전을 사용합니다.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/koreafonts/fonts@8c4173b46423c37ab346aa04498596aca064670b/MoiraiOne/koreafonts.css">
```

```css
@import url('https://cdn.jsdelivr.net/gh/koreafonts/fonts@8c4173b46423c37ab346aa04498596aca064670b/MoiraiOne/koreafonts.css');
```

직접 선언하는 경우:

```css
@font-face {
  font-family: "Moirai One";
  font-weight: 400;
  font-style: normal;
  font-display: swap;
  src: url("https://cdn.jsdelivr.net/gh/koreafonts/fonts@8c4173b46423c37ab346aa04498596aca064670b/MoiraiOne/MoiraiOne-Regular.woff2") format("woff2");
}
```
