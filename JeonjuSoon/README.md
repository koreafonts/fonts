## 웹폰트 적용

KoreaFonts 소유 jsDelivr 배포 버전을 사용합니다.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/koreafonts/fonts@cdn-005-v3/JeonjuSoon/koreafonts.css">
```

```css
@import url('https://cdn.jsdelivr.net/gh/koreafonts/fonts@cdn-005-v3/JeonjuSoon/koreafonts.css');
```

직접 선언하는 경우:

```css
@font-face {
  font-family: "Jeonju Soon";
  font-weight: 300;
  font-style: normal;
  font-display: swap;
  src: url("https://cdn.jsdelivr.net/gh/koreafonts/fonts@cdn-005-v3/JeonjuSoon/JeonjuSoon-Light.woff2") format("woff2");
}
@font-face {
  font-family: "Jeonju Soon";
  font-weight: 400;
  font-style: normal;
  font-display: swap;
  src: url("https://cdn.jsdelivr.net/gh/koreafonts/fonts@cdn-005-v3/JeonjuSoon/JeonjuSoon-Regular.woff2") format("woff2");
}
@font-face {
  font-family: "Jeonju Soon";
  font-weight: 700;
  font-style: normal;
  font-display: swap;
  src: url("https://cdn.jsdelivr.net/gh/koreafonts/fonts@cdn-005-v3/JeonjuSoon/JeonjuSoon-Bold.woff2") format("woff2");
}
```
