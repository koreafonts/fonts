# KoreaFonts font collection

Original font files and webfonts provided by KoreaFonts. Copyright and license conditions belong to each original publisher.

Each directory contains publisher credits and preserved LICENSE.txt notices. Files are offered only when their recorded delivery conditions are satisfied; other directories provide information and publisher links. manifest.json lists the current available files, SHA-256, byte sizes and publisher sources.

Historical CDN commits may remain cached after a delivery correction. Current files and links are the supported release.
