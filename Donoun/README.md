## 설치용 원본 다운로드

TTF·OTF 파일은 내려받은 뒤 운영체제에 설치해 사용할 수 있습니다. 가변 폰트는 파일명에 표시합니다.

| 파일 | 형식 | 크기 |
|---|---|---|
| [Donoun.otf](https://github.com/koreafonts/fonts/raw/refs/heads/main/Donoun/Donoun.otf) | OTF | 0.84 MB |
| [Donoun.ttf](https://github.com/koreafonts/fonts/raw/refs/heads/main/Donoun/Donoun.ttf) | TTF | 0.47 MB |

## 웹폰트 적용

파일 배포 조건에 따라 KoreaFonts의 CDN 코드와 웹폰트를 제공하지 않습니다. 제작자의 공식 배포처와 이용조건을 확인하세요.

## 사용 범위

| 용도 | 범위 | 조건 |
|---|---|---|
| 앱 임베딩 | 허용 | — |
| 상업 이용 | 허용 | — |
| 로고 | 허용 | — |
| 수정 | 미확인 | 보유 고지는 변형 재배포·유료 판매 또는 글자 외형 사용의 제한을 명시하지만 모든 독립 파일 수정 권리를 허락하지는 않습니다. 파일 변경 허락은 미확인입니다. |
| 포장 | 허용 | — |
| 인쇄 | 허용 | — |
| 재배포 | 허용 | 보유 고지에서 변경되지 않은 원본의 재배포를 허용합니다. 제작자·저작권 고지와 해당 라이선스를 유지하고 글꼴 자체를 유료로 판매하지 않습니다. 파일 수정·변형 허락과는 별개입니다. |
| 서브셋 | 미확인 | 보유 고지에서 독립적인 서브셋 허락을 확인하지 못했습니다. 변형본 재배포 제한도 적용됩니다. |
| 영상 | 허용 | — |
| 웹 | 허용 | 현재 보유 웹파일이 제작자의 변경되지 않은 허용 배포본인지 확인하지 못해 KoreaFonts 웹폰트 제공은 보류합니다. 제작자 원본의 웹 사용 허락과 자체 파일 제공 승인은 별개입니다. |

세부 조건과 저작권 표시는 [LICENSE.txt](LICENSE.txt)를 확인하세요.
