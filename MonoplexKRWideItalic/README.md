KoreaFonts 소유 jsDelivr 배포 버전을 사용합니다.

```html

```

```css
@import url('https://cdn.jsdelivr.net/gh/koreafonts/fonts@309fddcc68a6c33d0f6bd12526a42c91aa819828/MonoplexKRWideItalic/koreafonts.css');
```
