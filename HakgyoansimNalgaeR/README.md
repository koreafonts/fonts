## 웹폰트 적용

KoreaFonts 소유 jsDelivr 배포 버전을 사용합니다.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/koreafonts/fonts@521f2ad908effdc06b876069f6e839e5181638d9/HakgyoansimNalgaeR/koreafonts.css">
```

```css
@import url('https://cdn.jsdelivr.net/gh/koreafonts/fonts@521f2ad908effdc06b876069f6e839e5181638d9/HakgyoansimNalgaeR/koreafonts.css');
```

직접 선언하는 경우:

```css
@font-face {
  font-family: "Hakgyoansim Nalgae R";
  font-weight: 400;
  font-style: normal;
  font-display: swap;
  src: url("https://cdn.jsdelivr.net/gh/koreafonts/fonts@521f2ad908effdc06b876069f6e839e5181638d9/HakgyoansimNalgaeR/Hakgyoansim_NalgaeR.woff2") format("woff2");
}
```
