# Y클로버체 — KoreaFonts

KoreaFonts에서 제공하는 설치용 원본 폰트와 웹폰트입니다. 폰트의 저작권은 원 제작자에게 있습니다.

- 제작자: KT
- 원본 배포처: https://www.yspotlight.co.kr/download/font?tabNo=4
- 라이선스: [LICENSE.txt](LICENSE.txt)

## 설치용 원본 다운로드

TTF·OTF 파일은 내려받은 뒤 운영체제에 설치해 사용할 수 있습니다. 가변 폰트는 파일명에 표시합니다.

| 파일 | 형식 | 크기 |
|---|---|---|
| [YClover-Bold.otf](https://github.com/koreafonts/fonts/raw/refs/heads/main/YClover/YClover-Bold.otf) | OTF | 0.73 MB |
| [YClover-Bold.ttf](https://github.com/koreafonts/fonts/raw/refs/heads/main/YClover/YClover-Bold.ttf) | TTF | 1.79 MB |
| [YClover-Regular.otf](https://github.com/koreafonts/fonts/raw/refs/heads/main/YClover/YClover-Regular.otf) | OTF | 0.53 MB |
| [YClover-Regular.ttf](https://github.com/koreafonts/fonts/raw/refs/heads/main/YClover/YClover-Regular.ttf) | TTF | 1.49 MB |

## 웹폰트 적용

KoreaFonts 소유 jsDelivr 배포 버전을 사용합니다.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/koreafonts/fonts@523f37656d669b21cc8be54e41a89cca516658b5/YClover/koreafonts.css">
```

```css
@import url('https://cdn.jsdelivr.net/gh/koreafonts/fonts@523f37656d669b21cc8be54e41a89cca516658b5/YClover/koreafonts.css');
```

직접 선언하는 경우:

```css
@font-face {
  font-family: "YClover";
  font-weight: 400;
  font-style: normal;
  font-display: swap;
  src: url("https://cdn.jsdelivr.net/gh/koreafonts/fonts@523f37656d669b21cc8be54e41a89cca516658b5/YClover/YClover-Regular.woff2") format("woff2");
}
@font-face {
  font-family: "YClover";
  font-weight: 700;
  font-style: normal;
  font-display: swap;
  src: url("https://cdn.jsdelivr.net/gh/koreafonts/fonts@523f37656d669b21cc8be54e41a89cca516658b5/YClover/YClover-Bold.woff2") format("woff2");
}
```
