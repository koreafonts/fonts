## 웹폰트 적용

KoreaFonts 소유 jsDelivr 배포 버전을 사용합니다.

```html

```

```css
@import url('https://cdn.jsdelivr.net/gh/koreafonts/fonts@dc1dfec45097712a7d03140a83c6afada636c9f6/ClimateCrisisKR/koreafonts.css');
```
